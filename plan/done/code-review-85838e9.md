## Контекст

Ревью коммита 85838e9 (план `plan/done/hit-knockback-ram/`). Замеры — на реальном ядре и игровых
`models.js`/`weapons.js`; сдвиг через 180 тиков после выстрела, у едущей цели — разница с заездом без выстрела.

| # | Замечание | Замер до правки |
| --- | --- | --- |
| 1 | Задний ход: толчок по ходу за потолком −65 гасит только демпфирование | отходит лицом к стрелку, в лоб — **10.0**; едет задом к стрелку, в корму — 2.6 |
| 2 | JS-тесты читают угол из строки `m1` (округление 0.01 рад ≈ 0.573°) | `spinFactor` 0.03: 0.749° (в отчёте 0.57°); 0.035: 0.874° (в отчёте 1.15°) |
| 3 | Едущая цель: `turn` не проверяется; у теста 7 нет нижней границы; «у кормы» — на деле у носа | центр при выстреле y = −3.75, курс +y |
| 4 | Продольная часть не учитывает `brake`/`drag` поверхности, боковая — `drag` | стоит, в лоб: песок 3.64, вода 3.45, грязь 3.07 (асфальт 4.98) |
| 5 | Ветка «в полёте» в `hit_state` недостижима: hitscan не достаёт летящий танк (группы коллизий) | — |
| 6 | `hit_state` копирует выборку поверхности из `Tank::update`; курс в `tanks.rs` — литералом | — |
| 7 | В `docs/*/core.md` неполный список фикстур на 260 | — |

Решение по балансу (пользователь: «как считаешь нужным»):

- **На ходу** (задний ход, масло, грязь): путь от толчка зависит от запаса тяги и потолка. Правила «√ для заднего
  хода» и «тяга не держит потолок — как без хода» дали скачок у порога (остаток масла: до 15–25 ед.), поэтому
  заменены одной моделью `motion::drive_shift` (закрытая формула пути на ровном, сверена с пошаговым прогоном):
  продольная часть подбирается так, чтобы путь был как у эталона — вперёд по асфальту, толчок против хода.
  Замер на ходу (к/от стрелка, вперёд/задом; асфальт, песок, грязь, вода, масло): **3.5–5.0** (было 2.6–27).
- **Поверхности.** Все части масштабируются сопротивлением относительно асфальта, как уже сделано для `grip`:
  вдоль без хода — `(D + brakingFactor·brake + drag) / (D + brakingFactor)`, вбок — `(D + G·grip + drag) / (D + G)`.
  На асфальте отношение ровно 1 — прежние числа бит-в-бит.
- **`spinFactor`** остаётся 0.03 (0.75° при пороге 1° — с запасом); меняется только точность замера.
