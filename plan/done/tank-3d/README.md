# План: низкополигональная 3D-модель танка

Танк — плоский квад (`PerspectiveMesh`), который наклон, отдача и реакция на взрыв только перекашивают: у него нет
граней, и это читается как искажение картинки. Решение пользователя: настоящая низкополигональная модель — корпус с
лобовым листом, гусеницы, восьмигранная башня, ствол с дульным тормозом. Модель поворачивается по курсу, тангажу,
крену и повороту башни как твёрдое тело и рисуется почти сверху с ОГРАНИЧЕННЫМ наклоном от центра экрана (честная
проекция карты `shear 0.22` на уровень вытянула бы бока на краю экрана длиннее корпуса — причина, по которой
экструзию корпуса убрали). Грани освещены по своим нормалям тем же светом `tilt.lightDir`.

Все правки — в `vimp-tanks`, клиент; ядро, физика и формат кадра не меняются. Правила работы — как в
`plan/night-city-fixes.md` → «Правила на каждом этапе» (без коммитов, парные `docs/en|ru`, CHANGELOG, тихие проверки,
ручная проверка в `npm run dev`).

Связь с `plan/tank-volume.md`: этап 4 («башня выше корпуса») заменён этой моделью; реакция на взрыв (этап 8) и отдача
(этап 6) переезжают на модель в этапе 3; незакрытый этап 5 (паритет при `size: 3`) — независим.
