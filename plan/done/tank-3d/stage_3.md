# Этап 3. Рендер модели в `Tank` ✅ выполнен

1. Меш модели: один `Mesh` на танк с геометрией под максимум видимых граней (треугольники веером), атрибуты
   `aPosition`, `aUv`, `aShade`; шейдер `src/client/tank3d/shader.js` — `texel · shade · uColor` (тинт уровня и
   альфа как у меша PixiJS, см. разведку этапа 3 `tank-volume`). Позиции, UV и индексы пишутся раз в кадр только
   видимых граней в порядке отрисовки.
2. `Tank`: при `tankModel.enabled` живой танк рисуется моделью вместо `body`/`gun`: курс — поворот контейнера,
   `pitch`/`roll` — в `poseModel`, отдача (`recoilOffsets`) — откат ствола и башни, реакция на взрыв — наклон,
   встряска и подброс (`_viewZ`), просадка приземления — сжатие по `w`. Свет — `faceShade` (шейдер карт нормалей для
   модели не нужен). Остов пока прежний плоский.
3. Фары, дуло (`_muzzleWorld`), тень, see-through и тинт уровня — без изменений поведения.
4. Тесты `Tank.test.js`: модель создаётся при `enabled`, иначе прежний путь; отдача двигает ствол модели; подброс
   поднимает проекцию; просадка сжимает.
5. Документация `configuration.md` (таблица `tankModel`, абзац об объёме танка), `architecture.md` (рендер `Tank`);
   CHANGELOG `### Changed`. Проверки + ручная проверка: курсы, рампа, прыжок, отдача, взрыв, ночь, край экрана, FPS.

## Ход выполнения

- `src/client/tank3d/shader.js` — GLSL ES 3.0: `texel · aShade · uColor` (атрибут `aUv` — правило «без двух заглавных
  подряд»); `modelMesh.js` — `createTankModelMesh`: у каждой грани свои вершины, треугольники веером, буферы
  постоянного размера, индексы — видимые грани в порядке отрисовки, хвост нулями; `setAtlas`, `update`, `destroy`.
- `Tank`: `_modelAtlases` (при `tankModel.enabled` и ассете `tankModelTexture`), `_showModel` при оживлении (плоские
  `body`/`gun` прячутся), `_applyModel` раз за кадр после `_applyLight`: поза (тангаж/крен с добавками отдачи и
  взрыва, башня, откат ствола `_recoilOffsets.gun`, сдвиг = отдача корпуса + встряска, `squash`), наклон от камеры,
  проекция с `zScale` по `_viewZ()`, видимость и порядок, `faceShade`. Остов — плоский; `destroy` уничтожает модель.
  Геометрия модели общая на все танки.
- `tankModel.enabled: true`.
- Тесты: блок «3D-модель» в `Tank.test.js` (модель вместо плоских, без атласа — плоский путь, остов плоский, кадр
  получает проекцию/свет/порядок, отдача двигает только ствол, `destroy`), просадка в `project.test.js`.
- Документация: `configuration.md` (абзац об объёме танка → модель, таблица `tankModel`), `architecture.md` (меш
  модели); CHANGELOG `### Changed`.
- `npx eslint .`, `npm test` (731), `npm run build`, `npx vimp-contract` — зелёные.
- Замечание: кончик ствола модели (24.5 px рисунка) дальше точки вылета ядра (0.55 длины корпуса ≈ 22 px) — вспышка
  и трассер начнутся чуть внутри дульного тормоза; поправить при ручной проверке, если заметно.
- По ручной проверке: на горке цвета «выгорали» — палуба `0xeeeeee` без запаса яркости, а свет граней на наклоне
  поднимает верх до ~1.08 (238 × 1.08 > 255), фаски расходятся до 0.56…1.10. Палуба и фаски — стальной серый
  (`0xc8c9c4`, фаски `0xa9aaa5`/`0xb6b7b2`, запас ≈ 1.27). Обводка башни и ствола — тёмный тон цвета команды
  (×0.55), толщина 0.8 px вместо 1.7 (люк и тормоз — 0.6).
- По ручной проверке: на горке пропадала корма башни — сортировка граней по средней высоте ставила опущенные задние
  скаты башни раньше большой палубы (её средняя высота на наклоне выше). `visibleFaces` сортирует сначала по части
  (гусеницы → корпус → башня → ствол), внутри — по высоте; тест на наклонах в `project.test.js`.
- Ручная проверка пройдена (п. 5): компиляция шейдера, курсы, рампа, прыжок, отдача, взрыв, ночь, край
  экрана, FPS.
