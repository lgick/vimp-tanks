## Решение

Новый модуль `core/src/hit.rs` (только хост; из `motion.rs`, общего с репликой, уходит). Продольная часть: прогон
того же шага, что `Tank::update` делает вдоль курса (`step_throttle`, `drive_accel_on` на смеси с
`boost_hold_mix`, `drag`, `boost_damping_dv`, `decay_boost`) и демпфирования Rapier `v / (1 + D·dt)` — с толчком и
без; лишний путь — разница. Толчок подбирается (регула фальси, Иллинойс) так, чтобы путь совпал с эталоном:

- без клавиш хода — стоящий танк на асфальте от толчка × `idleFactor`;
- с клавишей хода — танк, едущий вперёд по асфальту на потолке с полным газом, от того же толчка против хода.

Боковая часть — закрытая формула: `(D' + G·grip + drag) / (D + G)`, `D'` = 0 при удержании бустера.
