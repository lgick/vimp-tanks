# Этап 9. Карта `downtown`

**Репозиторий:** `vimp-tanks`. **Зависит от:** этапов 1–8.
**Перед началом:** `plan/night-city/README.md` → «Общий контекст»; `docs/en/extending.md` целиком (правила 2.5D-карт);
`src/data/maps/overpass.js` и `terraces.js` как образцы построения сеток; по одному разделу «Поля карты» из этапов 2, 5, 7, 8.

## Цель

Ночной многоуровневый город, который использует все механики: поверхности, пропы, свет, анимации.
Графика — PNG-заглушки из генератора; финальный арт позже заменяет файлы без правок кода.

## 9.1 Генератор арт-заглушек

1. `scripts/generate-placeholder-art.js` — без зависимостей. PNG кодируется вручную: заголовок, `IHDR`,
   `IDAT` через `node:zlib.deflateSync`, CRC32. Скрипт детерминированный и запускается повторно.
   `npm run art:placeholders` в `package.json`.
2. Выход в `assets/img/` (файлы коммитит пользователь):
   - `city.png` — лист тайлов 32×32 (сетка, например, 16×8). Каталог кадров с именами — в
     `src/data/maps/city/tiles.js`: `export const T = { ASPHALT: 1, SIDEWALK: 2, LANE: 3, SAND: 4, MUD: 5, WATER: 6, OIL: 7,
     CONVEYOR_E: 8, CONVEYOR_W: 9, BOOST_N: 10, BOOST_E: 11, WALL: 12, ROOF: 13, SLAB: 14, RAILING: 15,
     RAMP_N: 16, RAMP_S: 17, RAMP_E: 18, RAMP_W: 19, CANAL_WALL: 20, … }` и `export const frames = [...]`
     (`BOOST_N` используется на юге — см. «Канал» в 9.2: проверка 9.5.3 требует, чтобы каждый тайл из `surfaces`
     стоял в сетке)
     (индекс в `frames` = id тайла, `frames[0]` — пустышка).
     Дополнительные кадры анимаций: вода ×4, шевроны конвейера ×4, стрелка бустера ×2 (пульс), вентилятор ×1 (для вращения).
     Узнаваемые плоские цвета плюс простой узор (разметка, шевроны, стрелки, рябь), чтобы механика читалась без арта.
   - Пропы: `prop_fence.png`, `prop_fence_broken.png`, `prop_crate.png`, `prop_crate_damaged.png`,
     `prop_crate_broken.png`, `prop_barrel.png` (без `broken`: копоть процедурная).
3. `scripts/check-pack.js` → `REQUIRED`: `dist/img/city.png` и все `prop_*.png`.

## 9.2 Геометрия `src/data/maps/downtown.js`

Параметры: `setId: 'c1'`, `step: 32`, `scale: 0.4` (тайл = 12.8 ед.), сетка **96 × 72**,
`spriteSheet: { img: 'city.png', frames }`, уровни `0` и `1`. Крыша-парковка для прыжка — уровень 1: прыжок
с рампы `0 → 1` приземляет на плиту своего уровня. Второй уровень прыжку не нужен и не вводится.
Сетки строятся функциями-конструкторами (`grid(fill)`, `rect(g, x0, y0, x1, y1, tile)`, `hline`/`vline`) по образцу
`overpass.js`. Все четыре границы карты замыкают стены `WALL`.
Id тайла — это индекс в `spriteSheet.frames` (`bakeTileLayer.js` берёт текстуру `frame${tileIndex}`). `0` в
`levels[n].map` означает «уровня здесь нет», поэтому тайл `0` не используется ни на одном уровне,
а `frames[0]` — пустой кадр-заглушка.

Районы (координаты в клетках `[col, row]`, приблизительные, уточняются при сборке):

| Район | Клетки | Содержание |
| --- | --- | --- |
| Запад — база `team1` | 2–14 × 20–52 | площадь, 8 респаунов уровня 0 (явный 4-й элемент `0`) |
| Восток — база `team2` | 82–94 × 20–52 | зеркально, 8 респаунов |
| Центр — «Neon Strip» | 36–60 × 28–44 | перекрёсток 4 полосы; **масляное пятно** 6×4 в центре; фонари по углам; вывески `HOTEL`/`BAR`/`GUNS` на фасадах (слой зданий уровня 1 — крыши) |
| Эстакада W–E | ряды 21–25, клетки 16–80 | уровень 1, плита 5 клеток шириной, перила, рампы `0 → 1` на концах (западная на `col 16–22`, `dir: 'east'`; восточная на `col 74–80`, `dir: 'west'`) и 2 разрыва в перилах над улицами (уступы). Проходит между северными районами (ряды 2–18) и центром (ряды 28–44), не над ними |
| Север-запад — промзона | 4–34 × 2–18 | 2 **конвейера** навстречу (E и W, по 12 клеток), ящики ×6, бочки ×4 в группе у конвейера (цепная реакция), здания с крышами уровня 1 и **вентиляторами** |
| Север-восток — стройка | 62–92 × 2–18 | **песок** и **грязь** пятнами, **заборы** ×10 с короткими объездами через стройку, ящики ×4 |
| Юг — канал | ряды 56–62 | **вода**-мелководье (проходима, медленно) через всю ширину; 2 моста уровня 1 с рампами `0 → 1`; бочки ×2 у стены канала; **бустер** `BOOST_N` 2×2 на южном берегу (ряды 64–65) напротив проезда к центру — разгон через воду на север, не перед рампой моста |
| Прыжок | 24–35 × 30–40 (запад центра, между базой `team1` и перекрёстком) | **бустер** `BOOST_E` 2×3 перед рампой `0 → 1` на крышу-парковку уровня 1 (≥ 8 клеток длиной до перил); площадка приземления проверяется в 9.5. Рампа не должна примыкать к эстакаде (другой ряд) |

Правила `extending.md`, которые нужно соблюсти:
- перила входят в `floor`;
- рампа выходит на `floor` без перил, перед выходом рампы нет перил;
- края плит без перил — только над проходимой землёй;
- все стены названы слоями;
- широкие рампы прямоугольные;
- `physicsDynamic[].level` у ящиков на плитах.

**Пропы и боты.** Граф навигации строится только по статике (`physicsStatic`, `walls`). Пропы в него не входят:
боты объезжают их лучами обхода (`bots/controller.rs`) и не стреляют по ним, чтобы расчистить путь.
Поэтому заборы, ящики и группы бочек ставятся **только на срезках, во дворах и в тупиках**. Ни один проп не должен
перекрывать единственный проезд между базами, выезд с базы или подход к рампе: иначе бот застрянет в
`ClearingObstacle`. Сценарий `bots_downtown.json` (9.6) проверяет это — ботов, застрявших у пропа, быть не должно.

## 9.3 Слои и объёмы

- Уровень 0: `layers: { 1: [асфальт, тротуар, разметка, песок, грязь, вода, масло, конвейеры, бустеры, рампы], 2: [стены зданий, граничные стены], 4: [стены канала] }`,
  `volumes: { 2: 1.0, 4: 0.25 }`. Стены канала — отдельный слой с низким объёмом: в общем слое с `1.0` они вытянулись
  бы на полный этаж, как здания.
- Уровень 1: `layers: { 1: [плита, крыша], 4: [перила] }`, `volumes: { 4: 0.35 }`. Вывески и вентиляторы
  (этап 8) ставятся на слой `1` уровня 1 (крыши), а не на `4` (перила).
- Все базы слоёв `< 40` (ограничение ночных карт, этап 7).

## 9.4 Наполнение `game`

- `surfaces`: `'0'` — `SAND`, `MUD`, `WATER`, `OIL`, `CONVEYOR_E/W` (`dir`), `BOOST_N/E` (`dir`); `'1'` — масло на эстакаде (одно пятно).
- `lighting`: `night: true`, `ambient: 0x3a4260`, фонари каждые ~8 клеток вдоль улиц, по 4 на перекрёстке,
  на эстакаде — свои фонари уровня 1 (проверка «свет уровня 0 не на мосту»).
- `animatedTiles`: вода (4 кадра, 4 fps), конвейеры (`speed` = `belt` из `coreParams.surfaces.types.conveyor`),
  бустер (пульс 2 кадра, `fps: 2`). У каждого описания ровно одно из `fps`/`speed` (этап 8.1).
- `signs`: 3–5 вывесок в центре, 1 `GUNS` у базы каждой команды; разные `flicker`.
- `decals`: вентиляторы на крышах промзоны.
- `physicsDynamic`: заборы, ящики и бочки с `game: { prop, imgDamaged?, imgDestroyed? }` и `img`; общее число тел ≤ 60
  (запас до лимита 255 и нагрузки на кадр).
- `respawns`: по 8 точек на команду (≥ `roomDefaults.maxPlayers / 2`), все с уровнем `0`, вдали от бочек.

## 9.5 Регистрация, проверки и баланс

1. `src/data/maps/index.js`: `downtown`.
2. `npm run art:placeholders && npm run build && npx vimp-contract` — нет ошибок `E2/E4/E5/E7`, манифест собирается.
3. `tests/config/game.test.js`: карта проходит общие проверки (тайлы, респауны), проверки этапов 7–8 и новую проверку
   «каждый тайл `game.surfaces` встречается в сетке своего уровня».
4. `tests/core/core.test.js`: `downtown` загружается в `GameCore` и `ClientCore` без ошибок, `map_info` отдаёт 16 респаунов.
5. Баланс (через `npm run sim` и вручную) — подобрать и записать значения в `coreParams.surfaces`/`props`:
   - дальность прыжка бустер + рампа: танк приземляется на крышу-парковку, а не в перила и не за край; если не так —
     уменьшить `boostMaxSpeed` или удлинить площадку;
   - на масле на полной скорости резкий поворот уводит в занос, но выход возможен;
   - песок и грязь заметно замедляют, но не запирают танк;
   - лента выносит стоящий танк за 2–3 с;
   - две бочки рядом дают цепную реакцию, взрыв бочки не убивает танк со 100 HP на краю радиуса.
   Изменение `coreParams` → `npm run core:test` (паритетные сценарии этапов 2–3 остаются зелёными).

## 9.6 Отладочные сценарии (`tests/scenarios/`)

По формату существующих (`"map": "downtown"`, `timeline` с `join`/`key`); **без утверждений об игровых правилах**
(они живут в `core/tests/sim.rs`):

`npm run sim:scenarios` — все проверки инвариантов раннера зелёные.

## 9.7 Ручная проверка (`VITE_MAP='downtown' npm run dev`)

Чек-лист:
- ночь читается, враги видны;
- фары поворачивают с корпусом и не светят сквозь плиту моста;
- неон мерцает, вентиляторы крутятся, шевроны идут со скоростью ленты;
- песок, масло, лента и бустер ощущаются и не дёргают локальный танк (нет телепортов);
- забор, ящик и бочка ломаются, обломки не мешают, копоть остаётся;
- после `/nr` (новый раунд, dev) всё восстановлено;
- дыра над игроком под мостом без тёмных пятен;
- радар без изменений;
- `render.js → lighting.enabled = false` и `animations.enabled = false` работают;
- FPS в пределах, указанных в этапе 7.
