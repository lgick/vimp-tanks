# Документация VIMP Tanks

`vimp-tanks` — игра-плагин для [движка VIMP](https://github.com/lgick/vimp-engine)
— командный танковый deathmatch: физика, правила и сущности рендеринга,
специфичные для этой игры, загружаемые движком динамически в рантайме по
контракту плагина (`GameManifest`/`HostPlugin`/`ClientPlugin`).

За всем, что не специфично для этой игры — P2P-транспорт, мастер-сервер,
Worker-инфраструктура браузерного хоста, MVC/рендер-каркас клиента, общий
Rust-crate движка — см. доки самого движка:
[vimp-engine/docs/ru/](https://github.com/lgick/vimp-engine/blob/main/docs/ru/README.md).
